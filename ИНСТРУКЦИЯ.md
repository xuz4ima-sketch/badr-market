# Сайт Издательского Дома «BadrBook»: как настроить и обновлять

Сайт лежит в папке `site` и публикуется на GitHub Pages: https://xuz4ima-sketch.github.io/badr-market/. Тексты и ссылки, которые чаще всего меняются, собраны в одном файле: `site/js/config.js`. Открывайте его в Блокноте или любом текстовом редакторе.

Разделы страницы идут в порядке документа «КОНСТРУКЦИЯ»: О нас (с фото книг издательства) → Наша продукция → Наши серии → Прайс-лист (кнопка скачивания Excel) → Где купить → Обратная связь.

## 1. Контакты, «Где купить», текст «О нас»

В `site/js/config.js` впишите значения между кавычками:

```js
phone: "+7 922 359-15-00",
whatsapp: "+7 922 359-15-00",
telegram: "+79223591500",          // номер в формате +7… или юзернейм без @
telegramChannel: "badrbook",       // без @
instagram: "badr.book",            // без @
```

Пока поле пустое, соответствующая кнопка на сайте не показывается.

**Города.** Список `stores`: у каждого города можно указать адрес магазина и ссылку на карту (Яндекс Карты или 2ГИС). Пустые поля просто не показываются:

```js
{ city: "Махачкала", address: "ул. Примерная, 1", map: "https://yandex.ru/maps/..." },
```

**Маркетплейсы.** В `marketplaces` вставьте ссылки на магазин издательства на Wildberries, Ozon и Авито. Пока ссылки нет, на сайте написано «Ссылка скоро появится».

**Тексты.** `about` («О нас») и `wholesaleTerms` («Условия опта», показываются под прайсом) пишутся между обратными кавычками `` ` ``. Абзацы разделяйте пустой строкой, а саму обратную кавычку внутри текста не используйте.

Название издательства всегда пишем так: **Издательский Дом «BadrBook»**.

## 2. Фото книг

Фото лежат в `site/assets/books` (формат WebP, ширина 720 px), а список книг в галерее и в «Наших сериях» — в `site/index.html`. Чтобы добавить или заменить книгу, проще всего прислать фото разработчику.

## 3. Как обновлять прайс

Прайс ведётся в Google Таблице. Посетители скачивают его кнопкой «Скачать прайс в Excel». GitHub каждые 15 минут забирает таблицу и пересобирает этот файл, а также число позиций и дату на сайте. Ничего загружать вручную не нужно: изменения появляются на сайте примерно через 15–25 минут.

| Колонка | Что писать |
|---|---|
| Серия | Название серии или издательства. Одинаковые серии собираются в один блок. |
| Наименование | Название книги |
| Опт, Розница | Только число: `375`, без «руб.». Пустая розница — на сайте будет «—». |
| Ед. | `шт` |
| Наличие | `есть`, `нет` или `под заказ`. Пусто — значит «есть». |
| Новинка | Любой текст, например `да`, — у книги появится метка «Новинка». |

Последняя строка — `#обновлено | 22.08.2024`. **Меняйте дату при каждом обновлении прайса**: на сайте и в Excel она показывается как «Цены актуальны на …».

**Нельзя:** переименовывать или переставлять колонки, переименовывать лист «Прайс», писать что-то ниже строки `#обновлено`.
**Можно:** добавлять, удалять и переставлять строки — на сайте порядок будет таким же.

Ссылка на опубликованную таблицу записана в `.github/workflows/pages.yml` (`PRICE_CSV_URL`). Если таблица когда-нибудь поменяется, нужно заменить ссылку там.

## 4. Ручное обновление прайса

Если нужно пересобрать прайс на своём компьютере: положите свежий CSV из таблицы («Файл → Скачать → CSV») в `site/data/prices.csv` и запустите `python обновить-прайс.py`. Скрипт пересоберёт `site/data/prices.js` (копию прайса, которая открывается даже без сервера) и `site/data/badr-price.xlsx` (файл для кнопки «Скачать Excel»). Для Excel нужен пакет `openpyxl`: `pip install openpyxl`.

## 5. Как посмотреть сайт на своём компьютере

Двойной щелчок по `index.html` откроет страницу вместе с прайсом (из встроенной копии `data/prices.js`). Чтобы всё работало как на настоящем сайте, запустите маленький сервер:

```
cd "путь\к\папке\site"
python -m http.server 8000
```

и откройте в браузере `http://localhost:8000`.
