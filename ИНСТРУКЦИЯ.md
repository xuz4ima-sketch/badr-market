# Сайт Badr Book: как настроить и обновлять

Сайт лежит в папке `site`. Всё, что вам понадобится менять, собрано в одном файле: `site/js/config.js`. Открывайте его в Блокноте или любом текстовом редакторе.

## 1. Контакты, текст «Об издательстве», условия опта

Откройте `site/js/config.js` и впишите значения между кавычками:

```js
phone: "+7 928 123-45-67",
whatsapp: "+7 928 123-45-67",
telegram: "badrbook_manager",      // без @
telegramChannel: "badrbook",       // без @
instagram: "badr.book",            // без @
```

- Пока поле пустое, соответствующая кнопка на сайте не показывается.
- Заявки из прайса уходят на номер `whatsapp` и в личный `telegram`.
- `about` и `wholesaleTerms` вставляются между обратными кавычками `` ` ``. Абзацы разделяйте пустой строкой. Пока текста нет, блок не показывается:

```js
about: `Первый абзац об издательстве.

Второй абзац.`,
```

Внутри текста не используйте символ обратной кавычки `` ` ``.

## 2. Прайс в Google Таблице (один раз)

1. Откройте [Google Таблицы](https://sheets.google.com) → «Пустой файл» → «Файл → Импортировать» → «Загрузка» → выберите `badr-price-list.xlsx` → «Заменить таблицу».
2. «Файл → Поделиться → Опубликовать в интернете». В первом списке выберите лист **«Прайс»**, во втором — **«Файл CSV»**. Нажмите «Опубликовать» и скопируйте ссылку.
3. Вставьте ссылку в `config.js`: `sheetCsvUrl: "…ссылка…"`.
4. Для кнопки «Скачать Excel» скопируйте ID таблицы из адресной строки: это часть между `/d/` и `/edit`. Вставьте её в `sheetId: "…"`.
5. Загрузите обновлённый `config.js` на хостинг. Больше этот файл трогать не нужно.

## 3. Как обновлять цены

Просто меняйте таблицу — сайт подхватит изменения сам, **примерно через 5 минут**. Правила заполнения есть и на листе «Как заполнять» внутри таблицы.

| Колонка | Что писать |
|---|---|
| Серия | Название серии или издательства. Одинаковые серии собираются в один блок. |
| Наименование | Название товара |
| Опт, Розница | Только число: `375`, без «руб.». Пустая розница — на сайте будет «—». |
| Ед. | `шт` |
| Наличие | `есть`, `нет` или `под заказ`. Пусто — значит «есть». Товар с «нет» виден, но его нельзя добавить в заявку. |
| Новинка | Любой текст, например `да`, — у товара появится метка «Новинка». |

Последняя строка — `#обновлено | 22.08.2024`. **Меняйте дату при каждом обновлении прайса**: на сайте она показывается как «Цены актуальны на …».

**Нельзя:** переименовывать или переставлять колонки, переименовывать лист «Прайс», писать что-то ниже строки `#обновлено`.
**Можно:** добавлять, удалять и переставлять строки — на сайте порядок будет таким же.

## 4. Если таблица недоступна

Сайт показывает последний загруженный прайс и предупреждение. Если прайс ещё ни разу не загружался, используется запасная копия `site/data/prices.csv` — это прайс от 22.08.2024. Её стоит изредка обновлять: «Файл → Скачать → CSV» из таблицы и замена этого файла на хостинге.

После замены `prices.csv` запустите `python обновить-прайс.py` (файл лежит рядом с этой инструкцией): он пересоберёт `site/data/prices.js` — копию прайса, которая открывается даже без сервера. Загрузите на хостинг оба файла.

## 5. Как посмотреть сайт на своём компьютере

Двойной щелчок по `index.html` откроет страницу вместе с прайсом (из встроенной копии `data/prices.js`). Чтобы проверить загрузку из Google-таблицы, запустите маленький сервер:

```
cd "путь\к\папке\site"
python -m http.server 8000
```

и откройте в браузере `http://localhost:8000`.

## 6. Размещение на badr.market

Сайт статический: на хостинг загружается всё содержимое папки `site` (`index.html` должен лежать в корне). Подойдёт любой хостинг статических сайтов, после загрузки нужно направить на него домен в панели регистратора. Этот шаг сделаем отдельно, когда выберете хостинг.
